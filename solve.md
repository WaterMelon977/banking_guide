X is a series of five consecutive multiples of 3 whose average is 36 and Y is a series of four consecutive multiples of 4 whose second smallest number is 13 more than the second highest number of X series. Find the sum of the smallest number of X series and the highest number of Y series?

**Options:**

* (a) 84
* (b) 96
* (c) 80
* (d) 90
* (e) 72

## Solution

**Observation:**
For five consecutive multiples, the average equals the middle term.

Series X:

[
30,;33,;36,;39,;42
]

Second highest number (=39).

Second smallest number of Y

[
39+13=52
]

Hence Y is

[
48,;52,;56,;60
]

Required sum

[
30+60=90
]

## Correct Option

**(d) 90**

## Q56 (Set 7). Set A contains three consecutive multiples of 7, and set B contains five consecutive odd numbers. The largest number in set A is equal to the smallest number in set B. If the average of the smallest number in sets A and B is 28, then find the difference between the 2nd smallest number in set A and the 2nd largest number in set B.

**Options:**

* (a) 11
* (b) 9
* (c) 13
* (d) 15
* (e) 21

## Solution

**Observation:**
Let Set A be

[
x,;x+7,;x+14
]

Since the largest of A equals the smallest of B,

[
\text{Set B}=x+14,;x+16,;x+18,;x+20,;x+22
]

Given,

[
\frac{x+(x+14)}{2}=28
]

[
2x+14=56
]

[
x=21
]

Thus,

* 2nd smallest of A (=28)
* 2nd largest of B (=41)

Required difference

[
41-28=13
]

## Correct Option

**(c) 13**

## Q65 (Set 5). The ratio of time taken by a boat to cover a distance downstream to upstream is (2:3). If the boat covers (108) km downstream in (d) hours and (120) km upstream in ((d+4)) hours, then find the upstream speed (in km/hr) of the boat.

**Options:**

* (a) 18
* (b) 15
* (c) 21
* (d) 12
* (e) 24

## Solution

**Observation:**
The ratio (2:3) is for the **same distance**. So first convert it into the speed ratio.

For same distance,

[
T_d:T_u=2:3 \Rightarrow S_d:S_u=3:2
]

Now for the given distances,

[
\frac{108}{S_d} : \frac{120}{S_u}
]

Using (S_d:S_u=3:2),

[
\frac{108}{3} : \frac{120}{2} = 36:60 = 3:5
]

So,

[
d:(d+4)=3:5
]

[
5d=3d+12 \Rightarrow 2d=12 \Rightarrow d=6
]

Upstream time:

[
d+4=10\text{ hours}
]

Upstream speed:

[
\frac{120}{10}=12\text{ km/hr}
]

## Correct option

**(d) 12**

**Tip:** For boat problems, first check whether the given time ratio is for the **same distance**. Then convert it into the speed ratio before using different distances.
