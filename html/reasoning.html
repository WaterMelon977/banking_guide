Reasoning Guide for SBI PO / IBPS PO Prelims

Target: 20+ / 30 Marks

Puzzles & Seating Arrangements usually contribute 15-20 marks. Combined with easy topics, 20+ is achievable.

1. Overall Approach

Time Allocation (20 minutes):

  • Easy topics (Inequalities, Syllogism, etc.): 6-8 minutes
  • 2 Puzzle/SA sets: 10-12 minutes
  • Remaining: 2-3 minutes

Recommended Attempt Order:

  1. Inequalities + Syllogism
  2. Coding-Decoding / Blood Relation / Direction Sense (if easy)
  3. Easiest Puzzle / Seating set (usually Linear or Floor)
  4. Second Puzzle set (only if conditions are clear)
  5. Skip complex circular or multi-variable sets if time is short.

Key Rules:

  • Prioritise accuracy.
  • Attempt only questions where logic is clear.
  • Use rough sheet for clean diagrams.
  • Scan all questions in first 30 seconds.

2. Detailed Guides for Easy Scoring Topics

Inequalities

Steps:

  1. Decode the symbols carefully (e.g., $ means ≥, @ means <).
  2. Combine all statements into a single chain where possible.
  3. Check conclusions one by one.
  4. For possibility cases: Check if conclusion is “definitely true”, “possibly true”, or “false”.

Example:
Statements: A $ B, B @ C, C # D (assume $ = ≥, @ = <, # = ≤)

Conclusions:
I. A @ C
II. B # D

Solution: Combine → A ≥ B < C ≤ D
I. A < C → False (cannot be determined)
II. B ≤ D → Possibly True

Tip: Practise coded inequalities daily. Focus on “only a few” and “some not” patterns.

Syllogism (New Pattern)

Steps:

  1. Draw Venn diagrams for each statement.
  2. Combine diagrams.
  3. Check each conclusion:
    • Definite conclusions must follow in all possible diagrams.
    • Possibility conclusions check if there is at least one case where it holds.
  4. Use “All/Some/Some not/Only a few/No” carefully.

Example:
Statements:

  • All A are B.
  • Some B are C.
  • No C is D.

Conclusions:
I. Some A are C.
II. All D can be B.

Solution:

  • I: False (Some A are C is not definite).
  • II: Possibility → True (possible that all D are B).

Tip: Master “only a few”, “some not”, and possibility cases. Avoid assuming extra information.

Coding-Decoding

Types:

  • Letter Shifting
  • Reverse Order
  • Symbol based
  • Fictitious language

Steps:

  1. Identify the pattern from given examples.
  2. Apply the same logic to the question.
  3. Common patterns: +1/-1 shift, reverse, opposite letters, first-last swap.

Example:
If “APPLE” is coded as “BQQMF”, how is “ORANGE” coded?

Logic: Each letter +1
O→P, R→S, A→B, N→O, G→H, E→F → “PSBOHF”

Tip: Look for patterns in the first 2-3 words. Practise both forward and reverse coding.

Blood Relations

Steps:

  1. Draw family tree immediately.
  2. Use standard notations (+ for male, - for female, = for married).
  3. Identify generations clearly.
  4. Solve from the question person backwards.

Example:
A is brother of B. B is mother of C. C is sister of D. How is A related to D?

Tree:
A (male) — B (female, mother of C & D)
C (female) — D

A is maternal uncle of D.

Tip: Practise mixed blood relation (puzzle type) questions. Use “only son/daughter” clues carefully.

Direction Sense

Steps:

  1. Use coordinate system (North = +Y, East = +X).
  2. Draw path step by step.
  3. Calculate final position and distance.
  4. For shadow/turning questions, note time of day.

Example:
A person starts from point P, walks 5km North, turns right 3km, turns left 4km. Final direction from start?

Solution: Net displacement calculation + direction.

Tip: Practise shortest distance questions using Pythagoras (for 45° turns).

3. Puzzles & Seating Arrangement

General Solving Steps:

  1. Read all clues once.
  2. Identify definite information and fix positions first.
  3. Draw clear diagram (line, circle, table, stack).
  4. Add information layer by layer.
  5. Use elimination for possibilities.
  6. Verify with all conditions before finalising.

Linear Seating:

  • Note facing directions clearly.
  • Fix ends first.

Circular Seating:

  • Fix one person.
  • Handle inward/outward facing carefully (left/right reverses).

Floor / Box / Scheduling:

  • Use tables or vertical diagrams.
  • Add variables column-wise.

Tips for All Puzzles:

  • Start with fewer variables.
  • If stuck >2 minutes, move on.

4. Common Mistakes to Avoid

  • Spending excessive time on one difficult set.
  • Ignoring negative clues (“not”, “cannot”).
  • Messy or incomplete diagrams.
  • Attempting all sets without checking difficulty.
  • Poor time distribution between easy and puzzle questions.
